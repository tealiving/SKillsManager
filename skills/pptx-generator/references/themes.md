# 主题模板映射

## 内置主题（assets/templates）
- `minimal-business`：通用商务/教育/政务
- `dark-contrast`：深色对比/科技/数据
- `warm-light`：温暖消费/品牌汇报
- `tech-neon`：科技/互联网/产品
- `elegant-serif`：高端/品牌/战略
- `fresh-green`：医疗/健康/可持续
- `bold-corporate`：金融/制造/运营
- `tech-premium`：高端科技/年度汇报
- `slate-minimal`：极简灰蓝/管理层简报
- `executive-graphite`：深石墨/高管简报

## 选择建议
- 周报/周总结：`minimal-business`（默认自动匹配）
- 科技/产品/数据：`tech-neon` 或 `dark-contrast`
- 高端科技/品牌：`tech-premium`
- 商务/汇报/通用：`minimal-business`
- 极简管理层：`slate-minimal`
- 高管/董事会：`executive-graphite`
- 金融/制造：`bold-corporate`
- 医疗/健康：`fresh-green`
